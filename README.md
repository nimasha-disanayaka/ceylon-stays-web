# 🌴 Ceylon Stays — Property Owner Portal & Web Application

[![Next.js](https://img.shields.io/badge/Next.js-14.x-black.svg)](https://nextjs.org/)
[![React](https://img.shields.io/badge/React-18.x-blue.svg)](https://reactjs.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.x-cyan.svg)](https://tailwindcss.com/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.x-blue.svg)](https://www.typescriptlang.org/)

The frontend owner web application for **Ceylon Stays**, enabling Sri Lankan hotel, homestay, and restaurant hosts to manage listings, track earnings, monitor availability calendars, and experience an interactive animated demo.

---

## ✨ Features

- **Modern Dark Design System:** Custom glassmorphic dark theme (`#121212`) tailored specifically for high visual appeal and responsiveness.
- **Real-Time Earnings Dashboard:** Monitor total payouts, active occupancy rates, and pending traveler reservations.
- **Automated Availability Calendar:** Date-blocking mechanism to prevent double bookings.
- **Interactive Video Walkthrough Modal:** Animated step-by-step presentation showcasing real-time mobile booking and 1-click email approvals for guest visitors.
- **Responsive Layouts:** Full support for desktop, tablet, and mobile browsers.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS, Lucide Icons, Custom Utility Design Tokens
- **State & Logic:** React Client Components, Hooks (`useState`, `useEffect`)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
# Binds to 0.0.0.0 for local network mobile testing
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.
